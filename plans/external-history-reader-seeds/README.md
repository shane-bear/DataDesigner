# Derived reader manifest to native seeds

Consume the existing broad discovery ledger, never a hand-picked session list.
Verify sealed derived inputs; join every occurrence to its existing reader atom
and archived file inventory. Export metadata/reference seed rows, including opaque
sensitive gaps, without reopening raw histories. Native NeMo validates metadata
and preserves all rows in Parquet. Existing reader payloads remain explicitly
lossy views, not reconstructed native records or freshly verified raw files.

Stable source-occurrence identity is separate from input revision, logical work
identity and per-POST attempt identity. A typed JSON prompt envelope lets the
existing call boundary record declared work identity without parsing historical
commands or manufacturing identity from similar text. Native column tests bind
multiple seed rows to HTTP attempts; no engine/scheduler changes or model calls.
